# Чи вижив би я на Титаніку?

Навчальний пет-проєкт для курсу «Створення AI додатків з використанням Python».  
Веб-додаток на Streamlit з навченою ML-моделлю, яка передбачає ймовірність виживання пасажира на основі історичних даних Titanic.

## Опис проєкту

Користувач задає параметри пасажира (клас каюти, стать, вік, вартість квитка, кількість родичів на борту та порт посадки) і отримує:
- Прогноз: вижив би пасажир чи ні.
- Ймовірність виживання у відсотках (яка плавно перераховується при зміні будь-якого повзунка).
- Коротке пояснення, які фактори найбільше вплинули на такий результат.

## Датасет та ознаки

Використано датасет `titanic` з бібліотеки `seaborn`.

| Ознака | Опис |
| :--- | :--- |
| `survived` | Цільова змінна (0 — загинув, 1 — вижив) |
| `pclass` | Клас квитка (1, 2 або 3) |
| `sex` | Стать (`male` або `female`) |
| `age` | Вік пасажира (пропуски заповнено медіаною) |
| `sibsp` | Кількість братів, сестер або подружжя на борту |
| `parch` | Кількість батьків або дітей на борту |
| `fare` | Вартість квитка у фунтах |
| `embarked` | Порт посадки (`S`, `C`, `Q`) |

## Результати порівняння моделей

Дані розбито на train/test (80/20, `random_state=42`), крос-валідація `cv=5`:

| Модель | Accuracy | F1-score | ROC-AUC |
| :--- | :---: | :---: | :---: |
| DummyClassifier (baseline) | 0.5866 | 0.0000 | 0.5000 |
| DecisionTreeClassifier | 0.7989 | 0.7391 | 0.8463 |
| MLPClassifier (Neural Net) | **0.8268** | **0.7737** | **0.8813** |

Найкращі результати показала нейромережа `MLPClassifier`. Крім вищої точності, вона дає неперервний плавний розподіл ймовірностей, тому відсоток адекватно реагує на зміну кожного окремого параметра (віку, вартості квитка тощо).

## Як запустити проєкт локально

1. Створити та активувати віртуальне середовище:
```bash
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

2. Встановити залежності:
```bash
pip install -r requirements.txt
```

3. Запустити навчання моделі (якщо потрібно перенавчити):
```bash
python src/train.py
```

4. Запустити веб-додаток:
```bash
streamlit run app.py
```

5. Запустити тести:
```bash
pytest -v
```

## Безкоштовний деплой на Streamlit Community Cloud

1. Завантажити репозиторій на GitHub.
2. Перейти на [share.streamlit.io](https://share.streamlit.io) та зайти через свій GitHub-акаунт.
3. Натиснути **New app**.
4. Вказати:
   - **Repository:** посилання на ваш репозиторій
   - **Branch:** `main`
   - **Main file path:** `app.py`
5. Натиснути **Deploy!**.
